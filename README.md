# SOLO Agency website

Static site (no build chain needed to host). Pages are generated by `tools/build.py`, so edit the copy there and run:

    python3 tools/build.py

Preview locally: `python3 -m http.server 8000` in this folder.

- Application and contact forms post to FormSubmit (https://formsubmit.co) and arrive as emails to solo.studios.co@gmail.com. The first submission asks for a one-time activation click.
- No fixed prices anywhere. Pricing is explained in `pricing.html`.
- Hosting: GitHub Pages from the `main` branch root.
